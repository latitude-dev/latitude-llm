First user: open the web URL and register — the first account creates the
organization. Magic-link sign-in needs a working email transport (settings in
config.extraEnv, passwords in secrets.extra).

AI features are optional: without provider keys the core observability stack
(trace ingest + viewing) works and AI-dependent features degrade per call.
Add provider keys via secrets.extra and select models with LAT_AI_* via
config.extraEnv.
